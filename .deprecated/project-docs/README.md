# Historical Project Documentation Archive

This directory is the tracked archive of the former repository `docs/` tree.

It preserves project-development provenance: ADRs, designs, guides, handoffs, issues, plans, research, and specifications. These files are historical and non-authoritative. Current product, architecture, integration, workflow, release, and package guidance lives under `plugin-docs/`, the root `README.md`, live source/tests/metadata, and `CHANGELOG.md`.

The archive is not part of the npm runtime artifact. Do not use it as the normal current-documentation reading path or update historical content merely to make it agree with later source. When an archive link points outside this directory, it is maintained only when preserving a usable historical reference requires it.
