# Delegation Harness Archive

Historical Freeflow Delegation Harness implementation and development evidence.

This archive preserves the final working-tree state from 2026-07-14, including unfinished source, generated output, tests, skills, specs, plans, research, handoffs, and eval evidence. It is retained for reference only.

Nothing in this directory is active Freeflow behavior. It is not built, tested, packaged, loaded, documented by the active plugin, or supported as a compatibility surface. Archived paths and links are historical and may not resolve outside this directory.

## Layout

- `delegation/`: core source, tests, TypeScript config, and generated output.
- `pi-extension/`: Pi integration source, generated output, and focused tests.
- `skills/`: archived model guidance and references.
- `docs/`: designs, specs, plans, research, and handoffs.
- `evals/`: focused prompts, registry entries, and reports.

Transient repo-local task state, transcripts, screen logs, and scratch output are intentionally excluded.
