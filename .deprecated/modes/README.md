# Removed Freeflow Modes

This archive preserves the former user-selectable mode surface for historical reference only. It is not a supported runtime, discoverable skill, configuration schema, command surface, or npm package resource.

- `skills/mode-contract/` preserves the former Mode Contract skill.
- `skill-eval/mode-contract/` preserves its current evaluation definition and fixture.
- `qualification/subjects/neutral/mode-contract/` preserves the neutral evaluation subject.

The active package now uses one adaptive Workflow. The former `defaultMode`, `interactionContract`, and `skills` configuration keys and all mode controls are breaking unsupported behavior. Use Git history for the complete pre-migration source context.
