# Legacy Skill Evaluations v1

Historical cases, durable results, and evaluator machinery from Freeflow's first skill-evaluation system.

This archive is documentary only. It does not define current skill readiness and must not be used as input to the active evaluator under `.skill-eval/`.

## Contents

- `fixtures/`, `prompts/`, `registries/`, and `suites/`: historical cases and case definitions.
- `reports/`: durable historical results, including command-surface, acceptance, iteration, and skill-family reports.
- `runbooks/` and `scripts/`: the retired execution and grading method.
- `schemas/`: historical evidence-index schema.

Raw generated files from the former `evals/runs/` directory were intentionally omitted. References to `evals/runs/...` or other `evals/...` paths inside archived documents describe their original locations and may no longer resolve.

Live skill source, current `.skill-eval/` cases, and current accepted evidence override this archive.
