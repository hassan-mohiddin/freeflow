# Output Router Archive

Retired Freeflow Output Router implementation, Pi integration, capability guidance, tests, evaluation fixtures, reports, and design material.

Nothing in this directory is active Freeflow behavior. It is not built, tested, packaged, loaded, documented as a supported capability, or exposed as a compatibility surface. Existing router vaults, adapter caches, and repository configuration are not rewritten or deleted; future Output Router work may use this archive as historical input for a new architecture.

## Layout

- `router/`: retired router source, generated output, tests, fixtures, reports, and evaluation scripts.
- `pi-extension/`: retired Pi integration source, generated output, and focused tests.
- `capabilities/`: retired Output Router skill and references.
- `plugin-docs/`: retired public capability guide.
- `docs/`: retired designs, specs, plans, research, handoffs, and issue notes.
- `skill-eval/`: retired Output Router subject material.

Archived source links may refer to the former live layout. The archive is documentary and is not a build target.
