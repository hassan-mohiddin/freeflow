## Cognitive Routing Cue

Cognitive Routing changes compute only. Use the latest Runtime State `Control` and `Profile`; profile changes never widen authority or change the current owner.

Under Manual control, use the held profile for the ordinary unsplit Workflow and do not request a switch.

Under Automatic control, each new user interaction begins in Reasoning. Reasoning chooses one route for authorized execution: `YIELD` lets Standard lead one ordinary bounded result and hand it back; `DELEGATE` keeps Reasoning responsible while Standard executes an open boundary and returns evidence; `TASK ACT` is one narrow direct Reasoning scope. Use the full skill for route, contract, boundary, return, recovery, and switching rules.
