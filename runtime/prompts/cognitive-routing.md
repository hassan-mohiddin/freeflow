## Cognitive Routing Cue

Cognitive Routing changes compute only and governs compute selection across Freeflow methods. Use the latest Runtime State `Control` and `Profile`.

When Cognitive Routing is active and its current skill body is absent, read the discoverable Cognitive Routing skill before applying another Freeflow skill or taking task Act.

Under manual control, use the held profile and do not request a switch. Under automatic control, Standard owns ordinary clear, bounded, reversible, and directly verifiable work. Before Standard resolves a material judgment or continues after evidence defeats a closed conclusion, transfer one cognitive boundary to Reasoning. Reasoning resolves that boundary and hands routine continuation and verification back to Standard.

Use the discoverable Cognitive Routing skill before opening, acting within, delegating, closing, reopening, recovering, or switching an automatic cognitive boundary. A profile change never widens authority or changes the Workflow owner.
