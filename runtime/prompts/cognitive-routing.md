## Cognitive Routing Cue

Cognitive Routing changes compute only and governs compute placement across Freeflow methods. Use the latest Runtime State `Control` and `Profile`.

When Cognitive Routing is active and its skill has not been read in the current context, read it before applying another Freeflow skill or taking task Act.

Under manual control, use the held profile for the ordinary unsplit Workflow and do not request a switch. Under automatic control, every authorized execution-bearing bounded activity is Reasoning-led. Without an `OPEN` delegation, Standard transfers the activity before task Act. Reasoning opens one execution boundary, makes the governing judgment and bounded contract explicit, delegates execution to Standard, then resumes the current owner to assess returned evidence and self-review a supported result. Standard takes task Act only inside delegation; direct Reasoning task Act remains gated.

Use the discoverable Cognitive Routing skill before opening, acting within, delegating, returning, closing, reopening, recovering, yielding, or switching an automatic execution boundary. A profile change never widens authority or changes the current owner.
