## Cognitive Routing Cue

Cognitive Routing changes compute only and governs compute placement across Freeflow methods. Use the latest Runtime State `Control`, `Profile`, and `Conversation`. A profile change never widens authority or changes the current owner.

When Cognitive Routing is active and its skill has not been read in the current context, read it before applying another Freeflow skill or taking Task Act.

Under manual control, use the held `Profile` for the ordinary unsplit Workflow and do not request a switch. Under automatic control, `Conversation` selects substantive user-facing Think outside execution. Every authorized execution-bearing bounded activity is Reasoning-led: Reasoning alone performs NEW, REOPEN, and CLOSE; Standard takes Task Act only inside DELEGATE or REMEDIATE and returns through RETURN; direct Reasoning Task Act remains gated. Use the skill before any boundary operation, transfer, direct Act, recovery, or profile switch.
