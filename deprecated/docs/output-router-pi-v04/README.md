# Output Router Pi v0.4 Archive

Historical documents from the abandoned Pi output-router implementation.

The primary snapshots under `handoffs/`, `issues/`, `plans/`, and `specs/` came from the final working tree of `feat/output-router-pi-v04` at `0b5b58494d2759c4c3176672e71cf45e88f09732`. That branch included `fix/output-router-audit-phase1` at `673745b00fe1c2f367ac4b6c7d18bb0c9dd95a3`.

The snapshot includes uncommitted edits to the completion plan and reference spec, plus three untracked handoffs. Implementation, eval, generated, configuration, and package changes were intentionally discarded.

`main-working-copy/` preserves the two differing untracked document versions that were present in the main worktree before cleanup. They are retained as historical variants rather than treated as active project documentation.

These documents are memory, not authority. Live repo evidence and current plugin docs override them.
