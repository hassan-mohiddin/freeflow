# Activation Boundaries

A description should route the skill without claiming the entire neighboring domain.

## Include

- the skill's job;
- verbs users naturally use for that job;
- concrete situations where the skill should load;
- distinguishing terms when adjacent work uses similar words.

## Exclude

- "help with" or "improve" without a domain;
- marketing or quality claims;
- exhaustive trigger taxonomies;
- nearby tasks the active instructions do not handle.

## Evidence

Use host-native discovery for activation claims. Directly injecting the body proves wording only.

Before production readiness, record:

- one natural positive prompt that causes the exact skill snapshot to be read or activated;
- one close near-miss prompt that does not activate it.

If the host cannot expose activation evidence, label the result diagnostic or unsupported.
