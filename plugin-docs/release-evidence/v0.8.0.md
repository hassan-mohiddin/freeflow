## Consumer-visible changes

- Freeflow compaction on native Pi, on by default: warnings before Pi's limit, agent-prepared compaction at a safe point with `freeflow_compact`, carried context, recovery, and Pi's own compaction kept as the fallback.
- Experimental Tool Execution on native Pi, off by default: a layer over Pi's tools with file tracking, clearer edit errors, `apply_patch`, and background commands.
- Cognitive Routing: projection on by default, prompt-cache reach and keep-alive across worker runs, reasoning shared only within one model and view, evidence selection and return in one response, and routing turned off visibly when the user picks a model or effort in Pi, with every routing control turning it back on.
- A Working Method section in Freeflow's prompt on Pi, the Write Docs skill, Track Work `slice record` and task `scratch/` directories.
- One `/freeflow settings` screen with Session, Personal, and Repository scopes.
- Freeflow's per-request, per-turn, and startup work no longer grows with session length; requests sent to providers are unchanged by those changes.
- Native Pi 0.99.1 or later required; Pi 1.0 and 1.0.1 supported.
- User documentation in `plugin-docs/` and developer documentation in `dev-docs/`; links to the moved developer pages from earlier releases break.
