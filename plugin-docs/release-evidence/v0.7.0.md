## Consumer-visible changes

- Removes selectable modes, mode commands, session mode state, and `defaultMode`; work now uses one adaptive Workflow.
- Removes the `interactionContract` and `skills` configuration toggles; the Interaction Contract and 25 base skills are always present when Freeflow is enabled, while optional capabilities remain independently gated.
- Adds Cognitive Routing support to normal Pi while preserving the PiFlow host path, and changes automatic routing so Reasoning governs user-facing interaction and boundary decisions while Standard executes bounded work and returns evidence.
- Refines runtime prompts, workflow guidance, skill-routing dependencies, the Pi support floor, and the Pi integration test target; fixes Runtime State ordering, native model/thinking override handling, and direct Pi skill-command expansion.
- Replaces the Schema 3 Track Work package with compact Schema 4 Markdown task memory and lifecycle commands. Existing Schema 2/3 records remain untouched and are not automatically migrated; explicit migration is deferred to later work.
- Keeps `resume` and `full` views, write-ahead Current Slice state, deterministic lifecycle transitions, and direct prose maintenance within the new record format.
- Preserves Schema 4 semantics and sections while keeping Current Context and Notes as ordinary Markdown and rendering Current Work, Future Work, and History entities as compact field-list rows; expanded Schema 4 records remain readable.

The Track Work format break and deferred migration boundary are recorded in [ADR 0012](../adr/0012-compact-schema4-track-work.md). The current skill remains behaviorally unverified; deterministic checks do not establish universal model behavior or skill readiness.
