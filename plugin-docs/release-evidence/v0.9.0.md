## Consumer-visible changes

- Ten capability skills replace twenty-five: the Workflow skill's cycle is in the always-present core guidance, and Discuss Work, Execute Work, Deliver Work, Track Work, Verify Work and Write Docs absorb the skills merged into them. Removed skill names, commands and merged references have no aliases.
- The runtime prompts and skills are one layer: core's cycle names each step's skill and its key references and scripts, the method lives only in the skills, and the Working Method keeps its rules and a one-line habit per step. Every description is broad and names the requests its references and scripts serve.
- The agent reads Discuss Work at a task's first request and Execute Work before its first tool call, read-only tasks included.
- Skills bring scripts that put a decision's facts in front of the agent (self-review, touch-map, choices, view recover, review-packet, the Deliver Work state and preflight scripts, plan-lint, artifact-check, and `skill-author compare`).
- On Pi, guidance notices push a skill's key lines at the tool call that needs them, including a request to read Execute Work when a run's first tool result comes back without it (`toolExecution.guidanceNotices`, on by default, with a Guidance notices row in `/freeflow settings`).
- On Pi, `/freeflow settings` has a Review row and a Reviewer model picker for the `review` setting, Runtime prompts and Skills rows with a switch per prompt and per skill, and every setting in all three scopes; a test fails when a config key Freeflow acts on lacks a row in any scope.
- The Working Method keeps tool output small on every host; the core guidance carries the agreement before building.
- Evaluate Behavior checks expectations and decisions when a definition loads, before any paid run, and refuses `host` inside a configuration's `runtime`.
- Verify Work sends a user-visible claim to the feature files covering the change, and Execute Work's self-review report lists them with whether each was driven live since.
- Pi 1.4.0 is the development and test host; Pi 0.99.1 or later is still supported.
