- Adds an optional Helper profile and `helper`, `executor`, and `both` delegation modes, with Helper handling normal support and Executor commissioned for substantive or consequential work.
- Adds session-only profile presets, attached evidence recovery, worker-specific continuation, and mode-aware settings and controls.
- Adds cache-aware Pi request assembly and qualified Astra effort-history adaptation while preserving unsupported-request fallback.
- Clarifies evidence selection, return preparation, manual-hold recovery, and pre-prompt reload behavior.
- Adds a practical user guide and expands README, Cognitive Routing, and PiFlow documentation around Memory, planned Context, Compute, recommended presets, and evidence/cost limits.
