# claude-opus-5-5

Freeflow's description of one checkpoint, to be checked again on each release. Each line says how it is known: **observed** in use, or **measured**, with where.

## As A Worker

- Hand it what needs judgement: builds whose decisions are not settled, judgement checks, the security review tier, a share of the coordinator's own work. It finishes and verifies thoroughly. (observed)
- It builds what the brief says without questioning it: told X is right, it takes X as right. Settle the approach before you brief it, and give it the condition under which to return instead (Work From A Brief). (observed)
- It applies every piece of feedback, so a return sent back with many notes comes back larger. Send back the defects that decide the result. (observed)

## For Your Position

### On Top

- A steer that changes an agreed decision: before applying it, say its consequence, the work it throws away and what else it changes, then do what the user says. You take a steer as right without asking; this reply is where the user sees its cost. (observed)
- Repeated steering grows scope, since you apply each steer. Sort each one as Discuss Work's When The User Returns Mid-Work says, and make new scope a new part. (observed)

### As A Worker

- If you can show that the brief's approach would produce wrong or wasted work, return that with the evidence. You tend to build what you are told. (observed)
