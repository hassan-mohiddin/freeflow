## Caveat: the tests command failed at load

The checkout had no `node_modules`, so `tools/run-tests.mjs` linked nothing and every test file that imports a package failed at load, and its output dropped the load error. Of the 15 clean groups, 10 showed failing tests in every arm (for example rv20-b 0 pass, 6 fail; with packages installed, 75 pass, 0 fail). Every arm saw the same broken output, so the arms compare like for like, but no arm had the test evidence the suite assumes. Both faults are fixed: `run-tests.mjs` keeps a load error and refuses to run without `node_modules`; with `npm ci`, every clean group's tests pass on Pi 1.0.1 and each failing defective group fails only its defect's own tests.

## Clean-rejection audit

The 18 clean rejections, read against the code (each finding checked at its cited lines, with reproductions outside the repository):

| Class | Rejections | Groups |
| --- | --- | --- |
| Real defect: the clean label is wrong | 3 | rv01-a, all arms |
| Reviewer wrong: a Blocking finding the code does not support | 8 | rv07-a ×3, rv16-a ×3, rv24-b ×2 |
| Contested: a wrong error code, not a missing refusal | 2 | rv08-a `full`, `pointer` |
| Inconclusive because the tests failed at load | 5 | rv14-b ×2, rv20-b ×3 |

- rv01-a's change (rs-97b149b0) is defective: `numberLines` numbers an extra empty line when the text ends with a newline (`carry.ts:123`), fixed later in `6766b171`. It is not yet relabelled.
- The wrong Blocking findings share one pattern: the reviewer blocked on a failure path it could not cite, or one its own reading showed cannot happen, such as a signal case Node never produces (rv07-a), a fixture outside the workspace (rv16-a) or a host API it guessed was missing (rv24-b), although Review Work already says to report Needs evidence there. This is the evidence behind the over-blocking fix (draft PR #72).
- Within each group, every rejecting arm raised the same main finding. `full` and `pointer` differed in verdict only on rv24-b, which the audit read as run-to-run variation.
