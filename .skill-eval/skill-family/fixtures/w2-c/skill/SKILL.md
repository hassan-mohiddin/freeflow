# Release Steps

Prepare a release from the verified branch.

## Steps

1. Confirm the verification report exists.
2. Update the changelog from the merged changes. Keep each step short.
3. Tag the release. Never tag before the verification report says Pass.
4. Publish the tag. Keep each step short.

## Hotfix

A hotfix task opens only this section. The steps above are not read on that route.

1. Confirm the verification report says Pass for the fix. Keep each step short.
2. Tag the hotfix. Never tag before the verification report says Pass.
3. Publish the tag. Keep each step short.

## Checklist

- Keep each step short.
- Record the tag name in the changelog.
