# Release Notes

Draft the notes from the merged changes, then check them.

## Steps

1. Collect the merged changes since the last tag.
2. Group them under Added, Changed, Fixed and Removed.
3. Run `notes-check` and fix what it reports.
4. Stop when the notes are drafted.

## Checks

- `notes-check` passes with no errors.
- A reviewer has read the notes.
