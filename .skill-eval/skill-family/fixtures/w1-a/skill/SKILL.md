# Handoff Notes

Write `HANDOFF.md` at the end of each work session.

## Sections

- Repository state: branch, last commit, uncommitted files.
- Work done this session.
- Next steps.

## Rules

- Leave out conversation details the next session does not need.
- Link files by their path from the repository root.
