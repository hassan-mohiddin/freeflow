# Tool Execution

Tool Execution works through the tools declared in the current request. Freeflow adds no tools of its own in this build.

Report what a tool actually returned: a failed or partial write is not a completed one, and a missing result is not an empty one. Tool visibility and this skill never grant permission to act.
